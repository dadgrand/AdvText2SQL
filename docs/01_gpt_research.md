# Phase 0 — исследование GPT и сравнение с Mistral

**Статус: результаты зафиксированы 23.10.2026.** Полные данные сохранены;
массовые прогоны в рамках организации файлов повторно не запускались.

## Условия

- GPT-5.4 mini через OpenRouter, temperature=0, reasoning=none, до 4096 выходных токенов.
- BIRD large: 241 вопрос, 8 баз. Ambrosia: 227 вопросов, 52 базы.
- Из исходных 240 вопросов Ambrosia явно исключены 13 вопросов трёх пустых БД.
  Это тот же набор ID, что у исторического baseline и best hybrid Mistral.
- Baseline — текущая ветка со всеми FEAT=false; это не весь pipeline из main.
- Исходный гибрид: FEAT_2,3,4,8,12,17,18,19,27,29,30,32,33,35.
  Для адаптированного BIRD отключены только FEAT_32/33; максимум 5 попыток.

## Полные большие прогоны

| Конфигурация | BIRD | Ambrosia |
| --- | ---: | ---: |
| Исторический Mistral baseline | 92/241 = 38,17% | 127/227 = 55,95% |
| Исторический Mistral best hybrid | 108/241 = 44,81% | 191/227 = 84,14% |
| GPT baseline | 99/241 = 41,08% | 160/227 = 70,48% |
| GPT, исходные 14 фичей | 93/241 = 38,59% | 166/227 = 73,13% |
| GPT, 12 фичей без FEAT_32/33 | **113/241 = 46,89%** | Не запускался |

GPT-гибрид без детектора даёт на BIRD +5,81 п.п. к GPT baseline. Он исправил
31 вопрос и испортил 17. Сравнение с историческими 44,81% включает смену модели
и не изолирует влияние фичей.

## Ambrosia: неоднозначность

| Конфигурация | Найдено / 67 | Ложных срабатываний / 160 | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Mistral baseline | 24 | 57 | 29,63% | 35,82% | 32,43% |
| Mistral best hybrid | 42 | 11 | 79,25% | 62,69% | 70,00% |
| GPT baseline | 0 | 0 | Не определён | 0% | 0% |
| GPT hybrid | 42 | 36 | 53,85% | 62,69% | 57,93% |

70,48% baseline соответствует предсказанию «всегда однозначно». Гибрид
действительно обнаруживает неоднозначность, но уступает Mistral по ложным
срабатываниям. Одинаковое число найденных вопросов не означает одинаковые ID.

Проверка промптов на малой выборке Ambrosia:

| --- | ---: | ---: |
| Текущий | 6/12 | 50,00% |
| Нейтральный | 6/12 | 50,00% |

Малое преимущество main не перенеслось на полную выборку.
К моменту организации файлов исходная A/B-папка уже отсутствовала; её
агрегаты сохранены в [отчёте проверки промптов](../research_results/runs/ambrosia_ambiguity_main_20261016/report.json).
Полные ответы варианта main сохранены, исходные ответы двух A/B-вариантов
заново не создавались. Старые одноразовые probe-скрипты удалены.

Исходный GPT-гибрид заблокировал 50 BIRD-вопросов как ambiguous.
Сравнение на этих же 50 вопросах:

## Ресурсы GPT

| Полный запуск | Токенов | Время | Изменение расхода ключа |
| --- | ---: | ---: | ---: |
| BIRD baseline | 441 456 | 34 мин 37 с | ~$0,358 |
| BIRD исходный гибрид | 1 320 300 | 49 мин 44 с | ~$0,689 |
| BIRD без FEAT_32/33 | 1 887 953 | 50 мин 05 с | ~$0,872 |
| Ambrosia baseline | 271 213 | 30 мин 11 с | ~$0,224 |
| Ambrosia гибрид | 535 497 | 51 мин 50 с | ~$0,515 |

Расход — разница снимков OpenRouter; возможны задержки учёта и параллельное
использование ключа. Это не точная бухгалтерская стоимость каждого запроса.
Старый лог Mistral Ambrosia baseline продолжался с checkpoint 179/240:
показанные в нём токены не покрывают весь запуск и напрямую несопоставимы.

## Выводы и следующий этап

Зафиксированы разные рабочие конфигурации для разных задач: BIRD без жёсткого
taxonomy-gating, Ambrosia с детектором. Улучшение зависит от модели и задачи.
Дальше — подготовка данных и испытания выбора фичей; сначала устранить ложные
метки, зависимости фичей и лишние вызовы. Подробный разбор всех 33 флагов:
[аудит](../research_results/runs/feature_audit_20261023/REVIEW_RU.md),
[большие одиночные абляции Mistral](../research_results/runs/feature_audit_20261023/mistral_large_ablation.md).

Ограничения: один запуск на конфигурацию; наборы уже использовались при
разработке; локальный BIRD evaluator сравнивает множества строк PostgreSQL,
а Ambrosia проверяет только метку неоднозначности, не корректность SQL.
