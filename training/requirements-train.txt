#   py -3.12 -m venv training\.venv-train
#   training\.venv-train\Scripts\python -m pip install -r training\requirements-train.txt
#
# Two non-obvious pins, both learned the hard way:
#   * torch 2.5.1+cu121 is the CUDA-12.1 wheel; the `--extra-index-url` below is what makes
#     `torch==2.5.1+cu121` resolvable. transformers must stay <5: transformers 5.x hard-requires
#     torch>=2.6 and silently disables PyTorch on this build ("Disabling PyTorch because
#     PyTorch >= 2.6 is required but found 2.5.1+cu121").
#   * trl 0.18.2, not 0.16.x: `completion_only_loss` (the field that masks the schema block out of
#     the loss) does not exist in trl 0.16.1, and 0.21+ renamed SFTConfig fields. 0.18.2 is inside
#     the >=0.16,<0.21 window AND exposes completion_only_loss.
#   * accelerate must be >=1.10: transformers 4.57 calls accelerator.unwrap_model(...,
#     keep_torch_compile=False), which older accelerate versions reject.
#   * PySocks: this workstation's Windows proxy is a SOCKS endpoint (socks=127.0.0.1:10808).
#     A fresh venv cannot reach PyPI without socks support, and pip cannot install PySocks without
#     network -- bootstrap it from a working interpreter:
#       python -m pip install --target training\.venv-train\Lib\site-packages pysocks
#
